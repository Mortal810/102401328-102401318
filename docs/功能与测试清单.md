# 验收与截图清单

1. 首页：打开 index.html，检查首页 26 条信息、彩色插画、导航、四个快捷类别入口与筛选。
2. 搜索：输入“耳机”，记录结果数量；搜索“zzzz_no_match_123”，应显示无结果。
3. 详情：打开“黑色耳机充电盒”，确认描述包含外侧轻微划痕，插画是深色耳机盒，发布人、学院与复制联系入口显示。
4. 评论：详情阅读预置评论，在下方新增一条线索，确认新评论显示；刷新后重新打开该物品验证保存（Chrome）。
5. 个人资料：我的 → 编辑 → 修改昵称、学院与签名 → 保存 → 刷新检查。
6. 寻物发布：输入名称、类别、发生地点与日期、联系信息，确认发布成功 → 我的发布可见。
7. 招领发布：切换“招领”发布，同样核验。
8. 状态：我的发布中点击“标记已找到/已归还”，确认后回首页、搜索和详情状态同步。
9. 表单边界：空名称、空联系信息、未来日期必须有验证提示。
10. 检查 Chrome DevTools Console 无页面脚本错误。
11. 在另外一台电脑通过 Chrome 双击 HTML 文件进行助教式复现检查。

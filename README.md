# 拾见｜福州大学校园失物招领

纯 HTML + CSS + 原生 JavaScript 校园失物招领网页，基于第一次结对作业 Figma 7 页原型进行实现与扩展。**本仓库可以离线使用，不需要安装 npm 包、启动服务或连接数据库。**

## 运行（助教/同学）

1. 下载 GitHub ZIP 并完整解压（保持 `index.html`、`css/`、`js/` 目录相对位置不变）。
2. 使用**最新 Google Chrome**，双击项目根目录的 `index.html`。
3. 可以立即浏览 26 条初始记录、按类别筛选、搜索（如“耳机”“青春广场”“校园卡”“书籍”）、查看详情并复制联系方式。
4. 底部导航进入“发布”，可发布寻物或招领信息，成功后在“我的”里查看并将状态更新为“已找到”或“已归还”。
5. 详情页可查看线索讨论与发表评论；“我的”支持修改昵称、学院与签名。

或者直接打开另行提供的 `校园失物招领_升级版_直接打开.html`：该单文件已内嵌全部 CSS/JS，无需保留子目录。

## 功能与实现

- **首页**：默认展示最新信息，全部 / 寻物 / 招领 Tab，类别筛选，进行中筛选，以及四个快捷分类入口。
- **搜索页 / 搜索结果页**：物品名称、物品类别、地点、详细描述、发布者昵称等词可匹配，含热门关键词和空结果提示。
- **详情页**：物品插画（或自行上传的照片）、时间与福州大学校园地点、发布者昵称和学院、联系信息、评论交流。
- **发布与成功页**：表单校验、图片压缩上传、发表成功后进入我的发布。
- **我的页面**：可编辑昵称/学院/签名、查看统计、修改自发布内容的状态。
- **附加特点**：一键复制联系方式、快捷分类、不同品类本地 SVG 插画、评论互动、浏览器刷新数据保留。

## 数据性质和隐私（重要）

- **26 条初始记录、姓名、评论和 QQ/微信/电话都属于虚构的界面测试素材，不对应真实失物或真实联系方式。请勿拨打或添加。**
- SVG 图片是根据**类别**绘制的示意插画，**不是遗失物真实照片或精确的品牌、划痕实拍**。用户自行上传的照片则在本浏览器内保存。
- 所有自发布信息、评论和个人资料只保存在当前 Chrome `localStorage`，**不同设备、不同浏览器之间不会同步**；清除站点数据将导致本地信息丢失。
- “我的发布”是基于当前浏览器 ID 的轻量演示权限，不是经服务器核验的真实账户体系；没有用户登录、云端协作、后台消息、实名认证。
- 图片较大时受浏览器本地存储配额限制。建议 JPG/PNG/WebP 且小于 3 MB；前端会缩放压缩。
- 从本地 `file://` 打开时，Chrome 通常允许保存本地数据，但不同安全设置可能限制本地存储。网页会给出存储受限提示。

## 开发人员测试

仅运行**单元测试**需要安装 Node.js 18+，网页本身不需要：

```bash
node --version
npm test
```

使用 Node.js 内置的 `node:test` 与断言库，不需要 `npm install`、Mocha 或其他第三方包。包含发布校验、搜索、筛选、状态切换、权限检查、评论和个人资料规则等测试。
